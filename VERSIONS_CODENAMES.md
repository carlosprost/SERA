# SERA — Nomenclatura Oficial de Versiones

Este documento sirve como referencia para los nombres en código de las versiones de SERA. Se utiliza un sistema basado en la mitología para las versiones mayores y en astronomía para las versiones menores.

## 🏛️ Versiones Mayores (Dioses de la Mitología)
Cada número de versión principal (X.0.0) lleva el nombre de un Dios que se mantiene fijo durante todo su ciclo.

| Versión | Dios | Atributo Sugerido |
| :--- | :--- | :--- |
| **v3.x** | **Ares** | Fuerza y Estabilidad (Actual) |
| **v4.x** | **Poseidón** | Fluidez y Expansión |
| **v5.x** | **Atenea** | Inteligencia y Estrategia |
| **v6.x** | **Hermes** | Velocidad y Transferencia |
| **v7.x** | **Hefesto** | Construcción y Herramientas |
| **v8.x** | **Artemisa** | Precisión y Enfoque |
| **v9.x** | **Apolo** | Claridad y Orden |
| **v10.x** | **Zeus** | Soberanía y Control Total |

---

## 🌌 Versiones Menores (Constelaciones)
Cada parche menor (X.Y.0) cambia de constelación. El código final del parche se concatena con el número de revisión (ej: `Orion-307`).

| Versión | Constelación | Estado |
| :--- | :--- | :--- |
| **vX.0.x** | **Orion** | Finalizado |
| **vX.1.x** | **Pegasus** | Finalizado (Caballo Alado) |
| **vX.2.x** | **Phoenix** | En uso (Renacimiento Relacional) |
| **vX.3.x** | **Lyra** | Planeado |
| **vX.4.x** | **Draco** | Planeado |
| **vX.5.x** | **Cygnus** | Planeado |
| **vX.6.x** | **Aquila** | Planeado |
| **vX.7.x** | **Cassiopeia** | Planeado |
| **vX.8.x** | **Andromeda** | Planeado |
| **vX.9.x** | **Centaurus** | Planeado |
