# SERA

## Sistema de Expedientes de Registro Avanzado.
---

## Descripción

Esta es una aplicación de escritorio que permite a los usuarios crear tablas según sus criterios específicos. Los usuarios pueden crear nuevos registros, actualizar información existente y eliminar registros de manera sencilla y eficiente.

## Características
- **Creación de Tablas:** Permite a los usuarios crear tablas personalizadas basadas en sus necesidades específicas.
- **Gestión de Registros:** Facilita la creación, actualización y eliminación de registros en las tablas.
- **Interfaz Intuitiva:** Ofrece una interfaz fácil de usar que permite a los usuarios navegar y realizar acciones rápidamente.
- **Filtrado y Búsqueda:** Permite a los usuarios filtrar y buscar registros dentro de las tablas para una gestión más eficiente.
