Primeros pasos

¿Qué es SERA?

Sistema de Expedientes de Registro Avanzado — una aplicación de escritorio nativa para Windows que te permite gestionar cualquier tipo de información estructurada de forma privada, segura y sin depender de servicios en la nube.

💡
Filosofía central: SERA funciona 100% offline. Tus datos nunca salen de tu computadora. No hay servidores de terceros, no hay telemetría, no hay cuentas requeridas.

¿Para qué sirve?

SERA es una herramienta universal adaptable a cualquier industria o necesidad. Algunos casos de uso típicos:

  • PyMEs: gestión de inventario, clientes, proveedores, presupuestos.
  • Estudios profesionales: expedientes de casos, seguimiento de clientes, vencimientos.
  • Organismos: registros de personas, eventos, auditorías internas.
  • Uso personal: colecciones, proyectos, registros médicos, biblioteca personal.

Primeros pasos

Primeros pasos

La primera vez que abrís SERA, el asistente de configuración inicial te guía por tres pasos para dejar el sistema listo.

Paso 1 — Configurar el operador

Ingresá tu nombre completo y tus iniciales. Estos datos se usan para:

  • Pre-cargar automáticamente el campo de firma en los reportes PDF.
  • Registrar al responsable en los logs de auditoría ISO 27001.
  • Personalizar el saludo en el dashboard principal.

Paso 2 — Crear la primera tabla

Una tabla es la unidad base de SERA. Equivale a una hoja de cálculo o una tabla de base de datos. Para crearla:

  1. Desde el dashboard, hacé clic en "Nueva Tabla" o usá el menú Archivo → Nueva tabla.
  2. Ingresá el nombre descriptivo de la tabla (ej: "Clientes", "Inventario").
  3. Definí si la tabla permite adjuntos de archivos.
  4. Guardá. La tabla queda disponible en el selector de la barra lateral.

Paso 3 — Definir los campos

Los campos son las columnas de tu tabla. Al crear o editar una tabla, el gestor de campos te permite agregar, reordenar y configurar cada columna con su tipo de dato específico. Ver la sección Tipos de campos para la referencia completa.

Paso 4 — Cargar datos

Tenés tres opciones para poblar una tabla:

  • Formulario manual: el botón + Nuevo Registro abre el formulario de alta con todos los campos configurados.
  • Importación masiva: desde un archivo Excel o CSV. Ver Importar Excel/CSV.
  • Portabilidad: importar un archivo .srx exportado desde otra instalación de SERA. Ver Portabilidad .srx.
Gestión de datos

Tipos de campos

Cada columna de una tabla tiene un tipo que determina cómo se valida, muestra e interactúa con el dato. SERA soporta 9 tipos nativos.

TipoIdentificadorDescripciónEjemplo
Texto text Cadena de caracteres libre. Soporta búsqueda full-text. "Juan Pérez", "Observaciones..."
Número number Enteros o decimales. Usable en fórmulas matemáticas. 42, 3.14, -100
Fecha date Selector de fecha. Soporta funciones de diferencia de días. 2026-05-30
Lista list Desplegable con opciones predefinidas. Admite múltiple selección. Activo / Inactivo / Pendiente
Booleano boolean Checkbox de verdadero/falso. ✓ / ✗
Adjunto attachment Referencia a archivo físico. Almacenado localmente, encriptado en exportación. contrato.pdf, foto.jpg
Relacional relation Vínculo a un registro de otra tabla. Ver Motor Relacional. → Tabla "Clientes"
Fórmula formula Columna virtual calculada en tiempo real. Ver V-Engine. = precio * cantidad
Texto Largo textarea Área de texto multilínea para contenido extenso. Notas, descripción extensa
⚠️
Los campos de tipo Fórmula son virtuales: no se almacenan en la base de datos y se recalculan en cada lectura. No pueden usarse como campos de destino en relaciones ni importarse desde Excel.
Gestión de datos

Motor Relacional

SERA implementa un sistema de relaciones entre tablas del estilo Lookup/Foreign Key. Permite que un registro de una tabla apunte a un registro de otra, resolviendo automáticamente la visualización del dato relacionado.

Crear un vínculo entre tablas

  1. Abrí el gestor de campos de la tabla origen (ej: "Pedidos").
  2. Agregá un campo nuevo de tipo Relacional.
  3. Seleccioná la tabla destino (ej: "Clientes").
  4. Elegí el campo de visualización de la tabla destino (ej: "Nombre"). Este es el campo que el usuario verá en el desplegable.
  5. Guardá la configuración.

Cómo funciona en tiempo real

Al editar un registro que tiene campos relacionales, SERA presenta un desplegable asíncrono inteligente que:

  • Carga bajo demanda los registros de la tabla destino para no saturar la RAM.
  • Permite búsqueda por texto dentro del desplegable.
  • Almacena internamente el ID del registro relacionado, no el texto visible (esto evita datos inconsistentes ante renombramientos).
  • Traduce el ID a texto legible en cada renderizado de la grilla principal.

Exportación relacional (.srx)

Al exportar una tabla con vínculos relacionales, SERA detecta recursivamente todas las tablas relacionadas y las empaqueta en un único archivo .srx, garantizando la integridad referencial al importar en otra instalación.

💡
La resolución de relaciones usa Prepared Statements nativos en Rust, blindado contra SQL Injection (OWASP A03). Los IDs nunca se interpolan como strings.
Gestión de datos

V-Engine: Fórmulas Inteligentes

El Virtual Engine (V-Engine) es el motor de cálculo de SERA. Permite definir columnas virtuales cuyo valor se calcula automáticamente en tiempo real a partir de otros campos del mismo registro.

Sintaxis básica

Los campos se referencian usando corchetes [nombre_del_campo]. Los argumentos de funciones se separan con punto y coma ;. Opcionalmente podés iniciar la fórmula con = (estilo Excel).

# Multiplicación de dos campos numéricos
[precio] * [cantidad]

# Concatenación de texto
CONCAT([apellido]; ", "; [nombre])

# Condicional: si el stock es menor a 5, mostrar "CRÍTICO"
SI([stock] < 5; "CRÍTICO"; "OK")

# Días restantes hasta el vencimiento
DIF_DIAS(HOY(); [fecha_vencimiento])
💡
El motor acepta tanto ; (punto y coma, estilo Excel/LibreOffice) como , (coma, estilo JS) como separador de argumentos. Se recomienda usar ; para mayor consistencia con herramientas de oficina.

Referencia de funciones

FunciónDescripciónEjemplo
SI(cond; si_true; si_false)Condicional ternario. Soporta AND y OR en la condición.SI([activo] == true; "Activo"; "Inactivo")
IGUAL(val1; val2)Compara dos valores ignorando mayúsculas/minúsculas.IGUAL([estado]; "activo")
ESTA_VACIO(val)Devuelve true si el campo está vacío o nulo.SI(ESTA_VACIO([nombre]); "Sin nombre"; [nombre])
CONCAT(a; b; ...)Concatena múltiples strings o campos.CONCAT([nombre]; " "; [apellido])
MAYUS(texto)Convierte el valor a mayúsculas.MAYUS([nombre])
MINUS(texto)Convierte el valor a minúsculas.MINUS([email])

Ejemplos completos

# Total con IVA (aritmética)
[precio] * [cantidad] * 1.21

# Nombre completo en mayúsculas
MAYUS(CONCAT([nombre]; " "; [apellido]))

# Estado de vencimiento
SI(DIF_DIAS(HOY(); [vencimiento]) < 0; "VENCIDO"; SI(DIF_DIAS(HOY(); [vencimiento]) <= 7; "PRÓXIMO"; "OK"))

# Campo vacío con fallback
SI(ESTA_VACIO([observaciones]); "Sin observaciones"; [observaciones])

# Comparación insensible a mayúsculas
SI(IGUAL([tipo]; "urgente"); "⚠️ URGENTE"; [tipo])
⚠️
Aislamiento de seguridad: las fórmulas se evalúan en un contexto cerrado sin acceso a variables globales del navegador, Tauri ni el DOM. No es posible ejecutar código arbitrario desde una fórmula.

Reglas de Formato Condicional

Las reglas de formato condicional permiten que SERA coloree automáticamente filas o celdas individuales de la grilla según condiciones lógicas definidas por el usuario.

Cómo crear una regla

  1. Abrí la tabla y hacé clic en Formato Condicional en la barra de herramientas.
  2. Elegí el campo sobre el que aplica la condición.
  3. Seleccioná el operador: igual a, contiene, mayor que, etc.
  4. Ingresá el valor de referencia.
  5. Elegí el color de resaltado para la fila o celda.
  6. Guardá la regla. Se aplica inmediatamente sin recargar.

Reglas múltiples y prioridades

Podés definir múltiples reglas para la misma tabla. Cuando un registro cumple más de una condición, se aplica la regla de mayor prioridad (la que está más arriba en la lista). Podés reordenarlas con drag & drop.

Operadores lógicos

Las reglas soportan condiciones compuestas con operadores AND y OR. Por ejemplo:

# Pintar de rojo si el stock es 0 O el estado es "Agotado"
[stock] == 0  OR  [estado] == "Agotado"

# Pintar de amarillo si el stock < 5 Y el estado es "Disponible"
[stock] < 5  AND  [estado] == "Disponible"

Buscador Global Spotlight

El Spotlight de SERA es un motor de búsqueda profunda que indexa simultáneamente todos los campos de todas las tablas de tu espacio de trabajo, entregando resultados en tiempo real con salto directo al registro.

Activación

MétodoAcción
TecladoCtrl + Shift + F
Barra de herramientasÍcono de lupa → "Búsqueda Global"

Cómo funciona

  • La búsqueda se ejecuta contra todos los campos de texto de todas las tablas en simultáneo.
  • Los resultados se agrupan por tabla y muestran el campo donde se encontró la coincidencia.
  • Al hacer clic en un resultado, SERA navega directamente a la tabla correspondiente y selecciona el registro en la grilla.
  • El motor usa LIKE parametrizado en SQLite, que es inmune a SQL Injection.

Búsqueda avanzada

Podés usar la paleta de búsqueda avanzada (Ctrl + P) para buscar por tabla específica o combinar filtros por campo. La paleta recuerda las últimas 10 búsquedas de la sesión.

Portabilidad Segura (.srx)

El formato .srx (SERA eXport) es el contenedor de portabilidad nativo de SERA. Es un archivo ZIP encriptado con AES-256-GCM que puede contener una o más tablas, sus relaciones y todos los adjuntos físicos.

Exportar datos

  1. Abrí la tabla y seleccioná Exportar → Exportar como .srx.
  2. Elegí si incluir archivos adjuntos en el paquete.
  3. SERA detecta recursivamente todas las tablas vinculadas y las incluye automáticamente.
  4. Ingresá la contraseña de cifrado (mínimo 8 caracteres).
  5. Seleccioná la ubicación de destino. El archivo se genera con extensión .srx.

¿Qué contiene un .srx?

  • manifest.json — metadatos del paquete, versión de SERA, lista de tablas incluidas.
  • tables/[nombre].json — esquema (definición de campos) de cada tabla.
  • data/[nombre].json — registros de cada tabla.
  • adjuntos/ — archivos físicos encriptados (si se eligió incluirlos).

Importar un .srx

  1. Desde el dashboard, seleccioná Archivo → Importar .srx.
  2. Elegí el archivo y luego ingresá la contraseña de descifrado.
  3. SERA autodetecta el contenido (multi-tabla o legacy unidimensional).
  4. Para colisiones de IDs primarios (registros ya existentes), SERA usa INSERT OR IGNORE — nunca sobreescribe registros existentes sin confirmación.
  5. Los adjuntos se restauran a la carpeta de datos local automáticamente.
⚠️
La contraseña de cifrado no se puede recuperar. Si la perdés, el archivo .srx es irrecuperable. Guardá tus contraseñas en un gestor de claves.
Exportación

Importar desde Excel / CSV

SERA puede importar masivamente miles de registros desde archivos Excel (.xlsx) o CSV. El motor de importación detecta la estructura automáticamente y permite mapear columnas de origen a destino.

Proceso de importación

  1. Abrí la tabla destino y hacé clic en Importar Excel/CSV en la barra de herramientas.
  2. Seleccioná el archivo desde el explorador nativo de Windows.
  3. SERA lee las primeras filas y muestra una vista previa con las columnas detectadas.
  4. En el mapeador, asignás cada columna del archivo al campo correspondiente en SERA.
  5. Confirmás la importación. SERA procesa los registros en lotes para no bloquear la UI.

Validación de datos

  • Los campos de tipo Fecha se validan y normalizan al formato interno.
  • Los campos de tipo Número rechazan strings no numéricos y registran un warning.
  • Los campos de tipo Lista solo aceptan valores que existan en las opciones definidas.
  • Los campos Relacionales no pueden importarse (requieren resolución de IDs internos).
✅
Para importar grandes volúmenes (10.000+ registros), SERA usa transacciones atómicas en SQLite que garantizan la integridad: si algo falla a mitad del proceso, el estado de la base de datos no queda inconsistente.

// API disponible para desarrolladores de plugins
window.SeraAPI.ui.registerPluginSettings({
  pluginId: 'mi-plugin',

Sandbox de seguridad

Todos los plugins se ejecutan en un sandbox estricto con acceso limitado a la API window.SeraAPI. No tienen acceso al sistema de archivos nativo, al sistema operativo ni a otras tablas que no hayan sido explícitamente autorizadas por el usuario.

Ecosistema

Seguridad y Privacidad

SERA implementa una arquitectura de seguridad defensiva por diseño, alineada con los estándares OWASP Top 10 e ISO 27001/27002.

Cifrado (AES-256-GCM)

El algoritmo AEAD (Authenticated Encryption with Associated Data) garantiza simultáneamente confidencialidad e integridad. Si un archivo .srx fue modificado externamente, SERA detectará la adulteración y rechazará la importación.

Auditoría ISO 27001

SERA registra los siguientes eventos en un log persistente en SQLite:

  • Inicio y cierre de sesión del operador.
  • Exportaciones e importaciones de datos.
  • Errores de acceso o permisos.
  • Cambios en la configuración del sistema.
  • Acciones masivas (borrado, importación).

El visor de auditoría está disponible en Ajustes → Auditoría. Los logs nunca contienen contraseñas ni datos PII sensibles.

Arquitectura defensiva (OWASP)

Amenaza (OWASP)Mitigación en SERA
A03 — InjectionPrepared Statements nativos en Rust (rusqlite). Cero interpolación de strings en queries.
A03 — XSSEscape automático con textContent en todos los renders de datos del usuario en el PDF.
A04 — Insecure DesignEvaluación de fórmulas V-Engine en contexto aislado sin acceso a globales del DOM o Tauri.
A08 — Integrity FailuresAES-256-GCM autentica el contenido del .srx. INSERT OR IGNORE previene colisiones en importaciones concurrentes.

Clave Maestra del Sistema (Phoenix Engine)

La Clave Maestra es la contraseña raíz que protege el acceso al sistema de cifrado de SERA. Se configura una sola vez en el primer inicio. No se almacena en texto plano — se usa como material de derivación de claves para el sistema de cifrado AES.

⚠️
Si perdés la Clave Maestra, no existe mecanismo de recuperación. Los datos cifrados con ella serán irrecuperables. Guardala en un gestor de contraseñas.
